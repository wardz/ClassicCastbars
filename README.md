# ClassicCastbars

Customizable castbars for Classic & Retail World of Warcraft. Type "/castbar" to open the options panel.  
Includes optional party & nameplate castbars, school lockout alerts, and uninterruptible cast state tracking for Classic Era.  

**Note: This addon is now in maintenance mode, so expect less frequent updates.**

## Midnight & Forever Update

Retail and Forever client is unsupported for now, as I don't have time to look into the new addon API introduced in patch 12.0.0.

## Classic Era Patch 1.15.0+

This addon is no longer mandatory for Classic Era to see *target* castbars. You may disable this addon now and enable castbars in `Blizzard Options -> Interface -> Show Enemy Cast Bar` instead.  

For anyone still using it for castbar customizations, make sure you're using version 1.7.2+ to support the new built in cast events.
